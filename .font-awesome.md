# Font Awesome Configuration

## Integration

- **Method:** Self-hosted SVGs rendered by Web Awesome's `wa-icon` component in the Eleventy documentation site.
- **Version:** 7.3.1, from the development dependency `@fortawesome/fontawesome-free`.
- **License:** Free.
- **Families:** Classic; solid, regular, and brands are available.

## Defaults

- **Style:** Solid.
- **Family:** Classic.

## Import Pattern

Eleventy copies the selected SVGs from the installed package to the documentation assets. The documentation's Vite entry points Web Awesome at that local SVG directory and respects the site's deployment path prefix. Use `wa-icon` with an icon name and `family="brands"` for brand icons.

## Conventions

Icons inherit their size and color from Web Awesome design tokens. Decorative icons sit beside visible text; icon-only controls have an accessible label. All icon assets are served locally, so the guide does not depend on an external icon CDN.
