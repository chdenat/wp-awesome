# Package skills

Read the package [`PROJECT_RULES.md`](../PROJECT_RULES.md) together with the matching skill. These skills adapt the useful WordPress, Eleventy, documentation, QA, and release practices from the originating repository while excluding parent-site design and production assumptions.

| Skill | Use it for | Adapted from |
| [`lgs-1920-component-delivery`](lgs-1920-component-delivery/SKILL.md) | Shared package verification and delivery workflow | LGS1920 standalone packages |
| --- | --- | --- |
| [`wordpress-eleventy-package-maintenance`](wordpress-eleventy-package-maintenance/SKILL.md) | REST client, authentication, Gutenberg conversion, normalized contracts, routes, integrations, declarations, and tests | Parent WordPress sync and Eleventy maintenance skills |
| [`wordpress-eleventy-docs`](wordpress-eleventy-docs/SKILL.md) | The package's 11ty guide, code samples, navigation, generated output, and documentation QA | Parent documentation-authoring, Eleventy maintenance, and site QA skills |
| [`wordpress-eleventy-package-release`](wordpress-eleventy-package-release/SKILL.md) | Version readiness, tarball inspection, clean-consumer verification, and registry release preparation | Parent site-release skill and package publishing requirements |

Use the release skill for publication preparation; an instruction to prepare a release is not by itself permission to publish it.
